# 一字溯源：默认计份口径 v1

基础原则来自 `skills/analyze-bazi-fene.md`。该文件没有完整的数值公式；用户于本次实现中明确授权按理解补齐。本文件记录产品补充口径，便于日后修订，不将补充口径冒充教材通则。

## 数据与对象

- 使用专业排盘当前显示的四柱和已选择的大运、流年、流月、流日。仅在浏览器中同步计算，无 API、AI、存储或扣点动作。
- 同字不同位置分别标识。地支概览以本气天干判断十神、查询根源和计份，其他藏干可分别点击查看，不将一个地支归为唯一十神。
- 藏干、本中余气与禄表对齐 taibu-core 3.4.0。根包含同干根及同五行异阴阳根，明确标识；不同气性不代表等量强度。

## 来源单位制（本产品补充规则）

1. 目标自身落点记 1 份。无根无气时仍可有这 1 个虚浮落点，不能据此认定有实际力量。
2. 每一处同五行藏根记 1 个地支来源。该地支的藏干、禄与库中相关藏气合并为同一来源，不重复加份。
3. 天干与坐下同五行根作为本口径的通根连体，合为 1 份。地支或藏干目标本身归在其所在的地支单位中，不另拆自身和本气。
4. 天干目标接受同柱地支藏干的生扶，来源地支计 1 份；外柱藏干仅因五行相生不直接计份。
5. 天干目标的相邻原局天干可作为生扶或同类供方；原局年与时不视为相邻。只在供方于当前盘面有同五行藏根时计入。
6. 地支本气或藏干目标，仅以同柱明透天干为生扶或同类供方，供方同样须有根；不凭同一地支内部相生生成循环路径。
7. 已选择的岁运天干与原局天干、其他已选择岁运天干视为当前时层的接触方，仍须满足相生/同类且供方有根。岁运藏根可以直接参与。此条是明确补充的岁运参与规则，并非把任意岁运柱无条件加一份。
8. 生扶/同类供方贡献自身来源单位，并将其地支根来源展开一层传递至目标；供方与坐下根仍按第 3 条合并。展开到地支藏气即终止，不递归寻找供方的其他生扶者。
9. 全部路径按物理来源位置（柱键 + 天干/地支）去重。同一来源经直接根、禄或多个生扶路径出现，合计只占 1 份，保留所有路径与合并理由。
10. 家内（日时）合并、年/月分别列家外，仅用于参与方归属账本；不把家内不同物理来源强压为一份，不以参与方数量限制展开份额。参与方账本列自身与直接根系；间接生扶以份额路径说明归处。

最终份额 = 去重后的来源单位数量。每份只表示一个来源单位，不代表相同强度、等额股权、人数、金额或所得。不能将某个字的份额与其他字直接相加作为全盘力量。

## 岁运、本命与边界

- 本命账本独立重算；当前账本使用所有已显示时层。对本命目标同时展示本命数、当前数和差额。新来源可能是岁运激活的原局供方，并非都在岁运柱上。
- 岁运目标没有自身的“本命份额”，展示当前来源份额即可。
- 六冲、六合只对目标或本命直接根的位置标注作用条件变化；不自动判冲断根、合化、开库或取得，不任意加减份。刑、害、破、三合成化等尚未加入作用提示。
- 木未、火戌、金丑、水辰作为库中相关藏气线索。已计入的藏根不因又称库而重复计份；是否开库与所得仍需另判。土库口径不统一，不自动指定。
- “无根无气（当前口径）”指当前盘面未检出同五行藏根、禄根、生扶或同类线索；月令旺衰、调候、制化并未折算为份数。
- 非法或缺失四柱、无效选择不输出结果；无效岁运不参与。切换大运清除旧流年/月/日，切换流年清除旧月/日；正在看的岁运列换字时自动更新，已消失的藏干关闭详情。

## 验证

`npm run test:bazi-sources` 覆盖十神 100 组、12 支藏干、来源去重、同柱连体、家内家外、虚浮落点、有根供方、单层展开、多路径合并、本命/岁运分离、岁运激活原局供方、冲合保留根和无效输入。
