## 行为

- 删除先进入5秒倒计时，可再次点击或按 Escape 撤销；切换浏览器标签、离开页面或将卡片切到后方会取消待删除状态。请求失败显示错误，不伪造成功。账号确认文字和管理员原有确认仍保留。
- 提示词框按聚焦、内容、加载状态伸缩；Enter 发送、Shift+Enter 换行，中文组合输入不会误发。普通问答无模型选择，Agent 使用添加上下文入口，无语音识别。
- 行内编辑有取消与重新生成，可使用 Ctrl/Cmd+Enter 提交；失败保留草稿。普通问答沿用原来的重生成流程，补充错误恢复。Agent 在服务端校验会话归属、原问题内容与消息数量，只使用修改点之前的历史；成功后通过事务替换后续消息，执行失败保留原记录，检测到并发变化则拒绝覆盖。
- 堆叠卡片最多同时展示4张，六张以上也可循环切换或搜索，不自动轮播。后方卡片露出名称、乾坤造、四柱，点击先展开；首张点击进入详情。首张显示四柱天干、地支及纵向藏干，不显示十神；使用专业排盘的颜色函数和藏干表。出生阳历、阴历、真太阳时与地点（有记录时）、排盘时间及编辑入口均保留。只留一个“编辑”入口承担原修改功能。
- 每次真正重新排盘记录 `rechartAt`，只修改名称时保留之前的排盘时间。所有预览四柱取保存结果，不另算一套命盘。

- 按用户补充标注核对卡片：每张后方露出的完整76px顶部均含名称、乾/坤造及四柱；最前方卡片在此基础上展示简盘和日期，未把后方预览误做成只有名称。
- 保存按钮适配上游逐字切换与右上状态徽标：真实 Promise 决定加载、成功和失败，禁止重复提交；失败保留重试，卸载不更新状态，成功2秒后恢复。移除示例里的固定2.5秒假请求；本地导出显示“已发起下载”，不声称磁盘保存完成。减少动态效果偏好停用旋转与缩放。
