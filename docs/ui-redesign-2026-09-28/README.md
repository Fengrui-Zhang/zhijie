# 智解交互细节优化（修正版）

最新一轮：用户指定 Delete Button、Prompt Box、Inline Edit、Rolling Card Stack、Save Button，并允许调整对应布局与结构。见 [第二轮接入记录](./implementation-round2.md)。下方为上一轮的约束与实施记录。

以用户 2026-09-28 的纠正为准：保留原项目的内容、布局、结构、配色、控件位置和文案，只改善交互的连续性与反馈。此前页面重设计和 preview.html 已撤回，不作为实现目标。

## 从 useLayouts 选用的交互

| 原状 / Before | 优化后 / After | 参考组件与作用范围 |
|---|---|---|
| 页签/分段选项直接切换选中底色 | 原位置和尺寸保持，选中背景平滑移动，点击立即生效；约180–220ms，快速切换可接续 | [Discrete Tabs](https://uselayouts.com/docs/components/discrete-tabs)：八字、紫微、风水时间层级、运势维度；多行布局分别适配，不强行改成单行 |
| 现有菜单、折叠区突然出现/消失或只做进入动画 | 从现有位置自然展开与收起，约160–220ms；中途反向操作从当前状态继续 | [Smooth Dropdown](https://uselayouts.com/docs/components/smooth-dropdown)：导航子项、现有展开内容；保留各菜单的原呈现方式 |
| 输入状态和附加选项变化较生硬 | 保留原输入框与上下文位置，平滑处理高度变化和焦点反馈；中文选字回车不误发 | [Prompt Box](https://uselayouts.com/docs/components/prompt-box)：现有聊天输入和上下文展开；不添加模型、语音、附件，不搬到新面板 |
| 按钮反馈不一致或全局缩放过强 | 延续原按钮外观，轻微按压、自然释放；约100–140ms，同一按钮只应用一套效果 | [Tactile Button](https://uselayouts.com/docs/components/tactile-button)：主要按钮；高频专业盘面小格不加立体摇晃 |
| 普通/加载/完成状态文字与图标突变，加载按钮被压暗 | 原有文字和图标平滑交接，宽度变化稳定，工作时文字清楚；只由真实请求驱动状态 | [Save Button](https://uselayouts.com/docs/components/save-button)：现有保存、复制、分析按钮；保留 ThinkingOrb，不复制演示定时成功逻辑 |

## 原组件的弹窗和详情面板

现有 DialogPortal、出生时间弹窗、手机更多菜单、宫位详情继续使用原有位置、尺寸与结构。只补齐轻量进入/退出过渡，约180–240ms；保持关闭、焦点回归和滚动锁。没有必要引入弧形边缘、改成另一种抽屉或新增拖拽手势。

## 实施范围

- 不重写标题、提示、业务内容；不新增说明文案或展示技术注释。
- 不改首页信息结构、命例卡片排列、表单步骤、导航分组、设置分栏。
- 不新增列表/卡片模式、搜索功能、更多菜单或页面；这些属于此前扩大了的范围。
- 不改专业盘面几何、算法、计费和路由；原有偏好继续生效。
- 交互瞬间响应；不等待动画播放完才执行操作。输入期间与长文阅读不做持续位移。
- 适配减少动态效果；键盘快速操作直接反馈；手机不依赖 hover。

## 验收方式

静止时与原项目对照：内容、文字、结构、控件位置一致；操作时检查快速连续切换、展开后立即关闭、长请求与失败、中文输入、手机触摸、键盘和减少动态效果。必须在原项目里验证，不再另做一套页面重设计预览。

已按此范围接入原项目交互。用户随后指定右上角账户信息使用 Smooth Dropdown，因此仅该处从居中弹层改为锚定原账户按钮的下拉菜单；其他页面结构、内容及文案保持原样。具体来源和调用点见 implementation.md。
